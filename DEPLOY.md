# Deployment

## Web — GitHub Pages

The web release build is deployed as a static site on GitHub Pages.

- **Site:** https://harryneufeld.github.io/qontract-app/
- **Source:** the `gh-pages` branch (auto-generated by the deploy script — do not edit by hand)
- **Base href:** `/qontract-app/` (GitHub Pages project-site path)

### Deploying

```bash
./tool/deploy_web.sh
```

To point the deployed app at a real backend instead of the local-dev default,
pass the API base URL (baked in at build time via `--dart-define`):

```bash
QONTRACT_API_BASE_URL=https://api.example.com ./tool/deploy_web.sh
```

The script:

1. runs `flutter build web --release --base-href /qontract-app/`
2. syncs `build/web/` into a throw-away worktree
3. commits + force-pushes it to the `gh-pages` branch

Verify after deploy (allow up to a few minutes for Pages to go live):

```bash
curl -fsI https://harryneufeld.github.io/qontract-app/
```

### One-time Pages setup (already enabled for this repo)

GitHub → repo **Settings → Pages → Build and deployment → Deploy from a branch**,
branch `gh-pages`, folder `(root)`. Via API:

```bash
gh api -X POST repos/harryneufeld/qontract-app/pages \
  -f "source[branch]=gh-pages" -f "source[path]=/"
```
